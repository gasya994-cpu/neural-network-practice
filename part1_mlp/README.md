# Часть 1. ООП-реализация многослойного перцептрона

## Описание
Полносвязная нейронная сеть с поддержкой:
- Произвольного числа слоёв (минимум 1 скрытый);
- Функций активации: sigmoid, ReLU;
- Обратного распространения ошибки (backpropagation);
- Обучения на мини-батчах с сохранением истории;
- Сохранения/загрузки весов в JSON.

## Структура
```
part1_mlp/
├── app/
│   ├── __init__.py
│   ├── exceptions.py   — кастомные исключения
│   ├── models.py       — класс NeuralNetwork
│   ├── manager.py      — класс DatasetManager
│   ├── utils.py        — вспомогательные функции
│   └── main.py         — консольное меню
├── dataset.csv         — тестовые данные
└── README.md
```

## Запуск
```bash
cd part1_mlp
python -m app.main
```

## Управление
Меню: создать сеть → загрузить CSV → обучить → предсказать → сохранить веса.
