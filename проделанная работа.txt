Работа: Практическая №1 — Простая нейросеть на Python

Что сделано:
1. Настроено виртуальное окружение (venv), зависимости из requirements.txt.
2. Реализована простая полносвязная сеть (MLP) с меню.
3. Проведены эксперименты:
   - Сеть A: архитектура 2-10-1, активация relu, 100 эпох → финальный loss: [вставь число]
   - Сеть B: архитектура 2-20-5-1, активация relu, 100 эпох → финальный loss: [вставь число]
4. Данные: использован файл test_data.csv (сгенерированный) / dataset.csv.

Вывод:
Более простая сеть (2-10-1) показала стабильное снижение ошибки. Более глубокая сеть (2-20-5-1) обучалась чуть шумнее, но к концу достигла сопоставимой ошибки. Это демонстрирует, что увеличение числа слоёв и нейронов не всегда даёт лучший результат на простых задачах.

Как запустить:
1. Распаковать архив.
2. В папке проекта: python -m venv venv
3. Активировать: .\venv\Scripts\Activate.ps1 (Windows PowerShell)
4. Установить зависимости: pip install -r requirements.txt
5. Перейти в part1_mlp и запустить: python -m app.main
